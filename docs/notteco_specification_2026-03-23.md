# Notteco 仕様書（2026-03-23 時点）

## 1. サービス概要
Notteco は、イベント参加者（搭乗者）と運転手情報を登録し、配車計算によって最適な乗り合い案を作成・共有する Web アプリケーション。

- 対応モード
  - **ノリアイ (`noriai`)**: 参加者の出発地点から共通目的地へ向かう。
  - **ソウゲイ (`sougei`)**: 共通基点を使いながら搭乗者の到着地点へ向かう。

## 2. 主な画面
- 管理者ページ `/admin/events/[id]`
  - イベント情報編集
  - 搭乗者/運転手の登録・編集・削除
  - 配車の実行（配車ボタン）
  - 配車結果、未割当者、ルート情報の確認
- 参加者ページ `/e/[id]`
  - 搭乗者としての登録
  - 運転手としての登録
  - 登録済み情報の編集・削除
  - 配車結果の参照

## 3. データモデル（主要）
- `events`
  - `case_type`, `destination_*`, `event_at`, `plan_is_latest` など
- `event_members`
  - `name`, `start_*`, `destination_*`
  - `can_use_rental_car`（レンタカー参加可否）
- `vehicle_offers`
  - `driver_name`, `start_*`, `capacity`
- `route_plans`
  - 配車計算結果（車ごとの順序、距離、時間、ルート表示用情報）

## 4. 機能説明

### 4.1 搭乗者・運転手登録
- 搭乗者は名前と地点情報を登録できる。
- 搭乗者には **「レンタカー参加が可能」** チェックがあり、後述の候補選定で利用される。
- 運転手は定員（運転手を除く）を設定して登録できる。

### 4.2 配車実行
- 管理者が「配車する」を押すと、搭乗者と運転手情報を使って配車計算を実施。
- 既存 `route_plans` を更新し、イベントの `plan_is_latest` を最新化する。

### 4.3 未割当者の表示
- 配車後、どの車にも割り当たらなかった搭乗者を未割当として表示。

### 4.4 レンタカー候補提案（未割当がいる場合）
- 条件
  - 配車結果が存在する
  - `plan_is_latest = true`
  - 未割当搭乗者が存在する
- ロジック
  1. 未割当かつ `can_use_rental_car = true` の搭乗者を対象にする。
  2. 最大3名を候補として評価する（負荷抑制）。
  3. 各候補について「本人がレンタカー運転手になる」前提で再配車をシミュレーションする。
     - 代替4シーター想定のため、**運転手以外の定員は3** とする。
  4. 改善効果のある候補のみ表示する。
     - 未割当人数が減る、または未割当同数で総距離が短縮される場合
  5. 表示順は、未割当人数が少ない順 → 総距離が短い順。

## 5. 非機能要件（現状）
- 配車候補評価は最大3名に制限し、画面表示時の計算負荷を抑える。
- 候補提案は最新配車時のみ表示し、表示の整合性を維持する。

## 6. 既知の前提
- レンタカー候補の定員は固定値（3名）で評価する。
- 候補提案は画面表示時に計算されるシミュレーション結果であり、実際の確定配車ではない。
